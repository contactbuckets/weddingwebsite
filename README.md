# ShaadiSutra — Indian Wedding Website Templates

A React + Vite marketplace for premium, customizable Indian wedding invitation websites.

## Getting started

```bash
npm install
npm run dev
```

## Stack

- React 18 + Vite
- React Router
- Tailwind CSS
- Framer Motion
- Lucide React

The current build is a polished marketplace frontend with template discovery, category filters, preview interactions, and a responsive layout. Checkout, authentication, customer publishing, and admin workflows are planned for subsequent phases.
